# Basketball

I made a VR game (PC VR Build). Everything was test with the Quest 3
You can grab the ball with the side button of the controllers.
The player cannot move, only their arms. THe score is shown on the left arm. When a hoop is done, the score is updated and a heptic feedback is triggered

A ball spawn every time you pick one.

Known bug:
- Sometimes, having both arms in the ball spawn can make it so it doesnt spawn any more balls
- Ball velocity would need a bit more work
